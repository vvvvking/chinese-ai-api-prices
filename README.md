Most "LLM pricing" pages cover text only. This one covers the whole Chinese stack — chat, image, video, audio, embeddings and 3D — because that is where the pricing questions actually get hard: per million tokens, per image, per second of video, per generation, per 1M tokens *for video*. Units are not interchangeable, so this repo groups by unit and never compares across them.

### New here? Start with the video pricing problem

Video is the one category where the same 8 seconds of output costs **$0.34 on the cheapest model and $5.44 on the most expensive** — a 16× spread that a per-second rate card hides. We wrote that comparison up, with a source link for every row:

## How to use these numbers

- **Never compare across units.** Per 1M tokens, per image, per second and per generation are different products. The `Unit` column is authoritative.
- **Prices move, and they move at different times of day.** Some providers publish peak and off-peak rates; a single number is a snapshot, not a contract. Re-read the JSON before you put a figure in a deck.
- **These are provider list prices.** The feed is published by [NovAI](https://aiapi-pro.com?utm_source=github&utm_medium=readme), a gateway that passes list price through at a 1.0× multiplier — so nothing here carries a reseller markup.
- **Free tier ≠ unlimited.** The five Flash models are free inside a daily cap; the current limit is on the free-tier page.

## About this dataset

Maintained by the NovAI team as a public, auto-updating reference. Prices are pulled from the live feed every day; if one looks wrong it is usually a stale upstream rate — open an issue and it gets fixed. If you build something on top of this feed, tell us and we will link it here.
